# Art direction

Use this reference to establish the campaign's visual system, vary composition, and construct connected panels. Let product evidence and brand assets choose the direction.

## Establish the visual system

Record a small set of reusable decisions: palette, type family/character and fallback, headline width/alignment, margins, capture/device scale, logo treatment, background/image treatment, and optional connecting motif. Use exact supplied marks and colors when required. Favor one recognizable idea over a collection of unrelated effects.

Select a direction that serves the product. A precision tool may benefit from a large interface and restrained annotations. A creative app may benefit from showing the work it produces. A personal service may benefit from a relevant situation or portrait. These are possibilities, not genre rules.

Use strong type hierarchy, deliberate line breaks, and enough negative space around the proof. Avoid shrinking the interface to fit a decorative phone arrangement. Check the result at listing size before spending effort on small ornamental details.

## Vary emphasis, preserve identity

Useful compositions include a large authentic screen, a focused detail with enough surrounding context, an outcome image supported by the interface, or a meaningful lifestyle scene. Change scale or placement to create rhythm while retaining the campaign's typography, color logic, and device treatment.

A flat capture can be more effective than a device mockup. Use a frame when it clarifies platform or context. Keep frame geometry plausible and consistent with the displayed device experience. Device chrome, reflections, fingers, and perspective must not hide the feature or make UI unreadable.

An opener can include branding, but the product should earn attention quickly. A brand-only title card is a deliberate choice, not a default. Verify the overall device set against current app-in-use guidance before calling it a submission candidate.

## Connected campaigns

Treat connected panels as independent images sharing a measured boundary. Never place essential words, a unique control label, or the only evidence for a claim across a crop boundary.

Before rendering, record for each connected pair:

- Export dimensions and panel order.
- The motif's crossing position, thickness, color, direction/tangent, and depth order at each shared edge.
- Which elements continue and which stop within a panel.
- The standalone composition if store spacing separates the images.

When the environment permits controlled composition, create a shared background or connecting element in one coordinate space and slice/export it at exact panel boundaries. Compose real captures and text as separate controlled elements where supported. Generate one individual finished export per panel even when a shared source spans several panels.

When relying on separate image generations, matching edge coordinates in a prompt is an intention, not a guarantee. Inspect actual edges in a gapless strip. After repeated drift, simplify the motif, use an allowed controlled method, or identify the unresolved seam. Do not call adjacent panels seamless solely because their colors match.

Connected artwork must also work with a gap, an isolated panel, and localized copy. Measure again after changing export dimensions or cropping; a resize that looks harmless can invalidate the join.

## Three-scale review

| Scale | Inspect |
| --- | --- |
| Full output resolution | Exact text, genuine UI content, logo shape, edge artifacts, frame geometry, crop, and export sharpness |
| Representative listing size | First-read benefit, recognizable app evidence, useful contrast, line breaks, and competing focal points |
| Sequence and connected strip | Story progression, repeated messages, consistent type/device treatment, actual seams, and standalone readability |

Record the representative preview scale when useful; do not claim one thumbnail width models every store placement. Fix issues that change understanding, truthfulness, or the visual system. Leave a strong panel alone when a revision would only express a different preference.
