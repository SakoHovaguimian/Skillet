# Note format

Write in plain language. Use a short action or outcome for features and improvements, and name the visible symptom for fixes. Prefer `Fixed duplicate reminders` over a ticket title or a generic `Bug fixes and improvements` line. Use one natural emoji at the start of each line and a single space before the text. Stay consistent across related lines.

This fictional example shows what to paste into the store field.

```text
✨ Pin your favorite lists.
⚡ Open saved items faster.
🐛 Fixed duplicate reminders.
```
